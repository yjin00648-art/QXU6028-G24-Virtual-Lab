# L1 AI Usage Record

- **Phase:** Regular L1 (original log dated 21 September 2026; supplementary figures retained in checkpoint).
- **Record consolidated:** 28 October 2026 (reviewed by Jin Zhengyang).
- **Tool:** ChatGPT Work / Codex (as stated in `AI_usage_log_L1_original.txt`).

## Purpose and instruction summary

We used AI assistance to inspect the G24 L1 data pack and implement the finite-temperature forward carrier-count integrals with the specified constants, integration limits, units and reference gates, evaluating the exact operating Fermi level from `L1_params.json` rather than the nearest CSV row, and producing the factor-sweep plot and numerical summary.

This summary is grounded in our preserved original log (`AI_usage_log_L1_original.txt`), while the four supplementary plots are documented retrospectively from their retained script, note and validation file.

## Output adopted and scope

We retained the band-edge (nB) and Fermi-referenced (nF) carrier densities, correction factor C = nB/nF, corrected mobility and factor-sweep plot as the official L1 output. Four supplementary plots (electron density, hole density, Hall coefficient and sheet resistance) use the selected L2 hard-gap model (Eg/kBT = 2.073) and are labelled explicitly as supplementary visualisations rather than an independent L1 gap measurement. No AI physics-model error was identified in L1.

## Checks and retained evidence

- Reference sweep ratios: C = 1.00 at EF = 0, approximately 2.00 at 0.073 eV, 2.60 at 0.100 eV and 5.10 at 0.200 eV.
- Exact operating point: C = 3.585277673110134, nF = 5.073654261627931e11 cm^-2 (matching the Chapter 3 closed-form formula), and corrected mobility = 20727.3768800189 cm^2 V^-1 s^-1.
- All five PNGs in our L1 checkpoint archive match `L1/recorded/` byte-for-byte, and L1 fields in the final `results.json` agree identically.
