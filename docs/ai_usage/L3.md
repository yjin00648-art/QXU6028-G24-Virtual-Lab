# L3 AI Usage Record

- **Phase:** Regular L3 2D spatial conductivity inversion (September 2026 practical work).
- **Record review.** I reviewed this retrospective summary, compiled on 28 October 2026.
- **Tool:** ChatGPT Work / OpenAI Codex (exact historical model sub-version not recorded).

## Purpose and instruction summary

We used AI assistance to implement the mean-zero 10x10 Tikhonov inverse problem from the G24 forward matrix A (128x100) and three repeated scans, construct the nearest-neighbour difference matrix L (180x100), evaluate the prescribed regularisation strength eta0 and a 5-point sensitivity sweep, compute central and off-centre point-spread functions (PSFs), and estimate the 95th-percentile detection limit delta95 from 500 repeat-noise reconstructions.

Because the full September chat transcript was not saved, this summary is reconstructed retrospectively from our retained L3 script, notes and outputs.

## Output retained

We retained the complete regular `results.json`, map and diagnostic figures, extrema, resolution, detection limit and notes. The reference map uses the prescribed eta0 rather than a manually tuned smoothness parameter, and yields a `clear fail` decision against the 3.0% specification. During repository consolidation, the complete regular L3 result was verified and preserved without substituting preview outputs.

## Checks documented in retained outputs

- Forward matrix checks: A = (128, 100), scans = (3, 128), L = (180, 100), numerical rank = 92, max |row sum| ~ 1.665e-16.
- Regularisation: eta0 = 0.001330992463; sweep factors 0.01, 0.1, 1, 10 and 100 all yield max|m| > 0.030.
- Map and extrema: 100 finite row-major entries with zero mean; positive maximum +0.04069367 at (-2.7, +2.7) and negative minimum -0.03286978 at (+2.7, -2.7) probe pitches.
- Resolution and noise: central/off-centre PSF FWHMs = 1.444295 / 1.303489 probe pitches (conservative value 1.444295); 500 noise simulations (seed 20260924) give delta95 = 4.0517e-6.
- Decision: max|m| - delta95 = 0.04068962 > 0.030 (`clear fail`).
